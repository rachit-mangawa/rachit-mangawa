# SVG Animations Archive

This directory contains the archived vector art schematics, interactive canvas draw components, and connecting spines previously used in the portfolio:

- `HeroArtwork.jsx` - Generative circular architecture blueprint schematic for Hero.
- `AstCompilerArt.jsx` - HeartFlow OS bare-metal AST compiler Xtensa LX7 schematic.
- `IngestionGraphArt.jsx` - UIDAI Aadhaar multi-lingual OCR pipeline & telemetry quadrant schematic.
- `AutodiffGraphArt.jsx` - TensorFlow Core reverse-mode gradient autodiff graph schematic.
- `AlgorithmicLatticeArt.jsx` - Competitive programming algorithmic lattice matrix schematic.
- `VectorSpine.jsx` - Connecting multi-variant spline path between alternating stages.
- `KeywordAnnotation.jsx` - Inline SVG annotation overlay paths (bracket, loop, underline).
- `ScrollDrawCanvas.jsx` - Base wrapper for `svg-scroll-draw` library lifecycle.
